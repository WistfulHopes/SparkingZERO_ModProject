# Sparking! ZERO Mod Project

A modding project for Dragon Ball Sparking! ZERO. You will need [this custom UE5 version](https://github.com/narknon/UnrealEngine-CEEnd/releases/tag/dbszv1) to run the project.

If you cannot see the above link, follow [these instructions on linking your Epic Games and GitHub accounts.](https://www.epicgames.com/help/en-US/c-Category_EpicAccount/c-ConnectedAccounts/how-do-i-link-my-unreal-engine-account-with-my-github-account-a000084938?sessionInvalidated=true)
